Drop-in compatible

Change one line. Keep your code.

fuegol speaks the Firecrawl v2 contract — same request bodies, same response shapes, same error envelope. Migrating is a base-URL swap and a new key.

# Firecrawl → fuegol.ink
- const base = 'https://api.firecrawl.dev';
- const key  = 'fc-...';
+ const base = 'https://api.fuegol.ink';   // or your own Worker
+ const key  = 'fgl_live_...';             // a new fuegol key

Your existing Firecrawl key is never automatically valid — issue a fuegol key (free, instant, below).

One engine, every surface

The complete web-data toolkit.

🔥 Cheapest-adequate-tier planner

Static HTTP fetch → readability extraction → HTML→Markdown for free. Escalates to a rendered browser only when a page truly needs JS, actions, or a screenshot. Margin by design.

📄 Scrape

Markdown, HTML, links, summary, and schema-guided JSON via Workers AI.

🕸️ Crawl

Async multi-page crawl on a Durable Object — robots-aware, resumable, cancelable.

🗺️ Map

Enumerate a site's URLs from sitemaps + link discovery in one call.

🔎 Search

Web search with optional result-scraping, via a pluggable provider adapter.

🧩 Extract

Structured JSON across many URLs, guided by your prompt + JSON Schema.

📑 Parse

PDF (native), HTML, and text documents → clean Markdown.

🛡️ SSRF-hardened

Private/metadata IP + redirect + DNS-rebind defense on every fetch.

🔌 Remote MCP

Firecrawl-compatible firecrawl_* tools over Streamable HTTP for Claude, Cursor & co.

💳 Real credit ledger

A transactional D1 ledger is the live authority for balance + usage — with enforced spend ceilings and user-set hard limits. Not an eventually-consistent meter.
