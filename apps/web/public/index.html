Drop-in compatible

Change one line. Keep your code.

fuegol speaks the Firecrawl v2 contract — same request bodies, same response shapes, same error envelope. The official @mendable/firecrawl-js and firecrawl-py SDKs run unchanged (verified 8/8 + 4/4 against production).

// @mendable/firecrawl-js — change the constructor, keep every call
- const app = new Firecrawl({ apiKey: 'fc-...' });
+ const app = new Firecrawl({ apiKey: 'fgl_live_...', apiUrl: 'https://api.fuegol.ink' });
  await app.scrape('https://example.com', { formats: ['markdown'] }); // unchanged
# firecrawl-py — same client, new api_url + key
- app = Firecrawl(api_key="fc-...")
+ app = Firecrawl(api_key="fgl_live_...", api_url="https://api.fuegol.ink")
  app.scrape("https://example.com", formats=["markdown"])  # unchanged
# Raw REST — swap the host and the bearer token
- curl https://api.firecrawl.dev/v2/scrape -H 'Authorization: Bearer fc-...'
+ curl https://api.fuegol.ink/v2/scrape  -H 'Authorization: Bearer fgl_live_...'

Your existing Firecrawl key is never automatically valid — issue a fuegol key (free, instant, below). The FIRECRAWL_API_URL / FIRECRAWL_API_KEY env conventions are honored too.

🔥 Cheapest-adequate-tier planner

Static HTTP fetch → readability extraction → HTML→Markdown for free. Escalates to a rendered browser only when a page truly needs JS, actions, or a screenshot. Margin by design.

📄 Scrape

Markdown, HTML, links, summary, and schema-guided JSON via Workers AI.

🕸️ Crawl

Async multi-page crawl on a Durable Object — robots-aware, resumable, cancelable.

🗺️ Map

Enumerate a site's URLs from sitemaps + link discovery in one call.

🔎 Search

Web / news / images search with optional result-scraping + time filters.

🧩 Extract

Structured JSON across many URLs, guided by your prompt + JSON Schema.

🤖 Agent & Monitor

Autonomous research runs, plus scheduled change monitoring with signed webhook alerts.

🖱️ Interactive browser

Persistent Puppeteer sessions — click, type, scroll across requests. Metered by the minute.

🔌 Remote MCP

Firecrawl-compatible firecrawl_* tools over Streamable HTTP for Claude, Cursor & co.

💳 Real credit ledger + preflight quotes

A transactional D1 ledger is the live authority for balance + usage — with enforced spend ceilings, user-set hard limits, and a deterministic /v2/quote that bounds cost before any job runs. Not an eventually-consistent meter.
